# ♻️ 우리동네 자원순환 도장깨기

**생활 속 자원순환과 올바른 분리배출을 재미있는 게임으로 배우는 환경교육 콘텐츠입니다.**

「우리동네 자원순환 도장깨기」는 일상에서 자주 만나는 폐기물과 분리배출 방법을 게임을 통해 익힐 수 있도록 만든 **모바일 환경교육 게임**입니다.

환경부의 분리배출 관련 안내와 공식 자료를 바탕으로 문항을 구성하고, 문제를 풀면서 분리배출 방법을 자연스럽게 익힐 수 있도록 설계했습니다.

## 🎮 게임 특징

* 4개의 레벨로 구성된 분리배출 퀴즈
* 제한시간과 하트 시스템
* 힌트를 활용한 문제 해결
* 레벨별 보스 문제
* 틀린 문제 다시 풀기
* 획득한 자원순환 도장 확인
* 게임 결과 공유 기능
* 모바일 화면에 맞춘 반응형 UI
* 별도의 회원가입이나 서버 없이 이용 가능

## 🌱 교육 내용

게임에서는 다음과 같은 생활 속 자원순환 내용을 다룹니다.

* 종이류
* 골판지
* 투명 페트병
* 플라스틱
* 스티로폼
* 캔류
* 유리병
* 비닐류
* 기타 생활폐기물
* 재사용과 재생이용 등 자원순환의 기본 원칙

문항은 단순히 정답을 맞히는 것에 그치지 않고, **왜 그렇게 배출해야 하는지**를 함께 이해할 수 있도록 설명을 제공합니다.

## 📱 이용 방법

웹 브라우저에서 게임을 실행한 뒤 자신의 연령대를 선택하고 게임을 시작하면 됩니다.

별도의 앱 설치나 회원가입 없이 모바일에서도 이용할 수 있습니다.

## ♻️ 게임의 기본 원칙

이 게임은 분리배출 방법을 임의로 만들어 제공하지 않고, 공식적인 환경 관련 안내와 자료를 확인하여 문항을 구성하는 것을 원칙으로 합니다.

지역별 수거 방법이나 배출 장소 등에 차이가 있을 수 있는 경우에는 해당 지역의 안내를 확인하도록 안내합니다.
